# 塔塔钓鱼

给塔塔冒险队「钓鱼大赛」用的本地窗口。画面识别按比例找按钮和滑块，不写死某一张截图的像素。校准只是备用。

`python app.py` 会直接打开窗口。

## 循环

1. 准备界面点绿色按钮。点之前先读左下角三叶草幸运。默认最低幸运 8，也就是满幸运才甩杆。低于就停止，并在本工具里提示你自己补道具。不自动使用道具，也不看道具倒计时。
2. 按钮变灰、浮漂在水里时不点。
3. 出现「就是现在!拉钩!!」和缩短的黄条时，在黄条结束前点钓鱼按钮。
4. 进入滑块后，红浮漂进黄色区域就点屏幕任意位置（不点鱼钩按钮）。「完美!」只是这一下的提示，鱼还没结束。一直重复到结算。
5. 结算标题可能是「恭喜获得」「刷新团队记录 / 刷新团队纪录」「刷新个人记录 / 刷新个人纪录」。鱼的样子和重量每次都会变。点一下屏幕关掉，回到绿钮。
6. 顶部大赛倒计时读到 0 就结束本轮会话。没读准的数字不会当成 0。

结算出现才算成功。错过拉钩或滑块中断算失败。无限次数一直钓到你手动停止，或大赛时间到。

## Windows + MuMu

1. 安装 Python 3.11 或更新版本（python.org 的安装包自带窗口库）。
2. 在这个目录执行 `pip install -r requirements.txt`。
3. 安装 Android platform-tools，确认命令行能运行 `adb`。
4. MuMu 里打开 ADB。常见端口：
   - MuMu 6：`127.0.0.1:7555`
   - MuMu 12：`127.0.0.1:16384`
   - 其它：`127.0.0.1:5555`
5. 在这个目录执行：

```bat
python app.py
```

窗口会自己打开。选 MuMu 或 H5，点「连接模拟器」。连上后状态是「已连接 MuMu」或「已连接 H5」。地址不对就填自定义端口。游戏停在钓鱼大赛，设好次数或无限次数、最低幸运，点「开始钓鱼」。

H5 如果开在模拟器里，同样走 adb，只是状态文案不同。

## 校准（只改点击位置）

自动识别已经按这几张界面做过：绿钮、灰钮、拉钩黄条、滑块、两种结算、幸运 8 和幸运 4。分辨率变了仍按比例找。认不出画面时不会开始，也不会空跑。

绿钮或拉钩点偏了，可以把相对中心写进本目录的 `calibration.json`。重新打开窗口后生效。只覆盖这两个点击点，画面状态仍靠识别：

```json
{"regions":{"green_button":{"x":0.50,"y":0.82},"hook_button":{"x":0.50,"y":0.82}}}
```

`x`、`y` 是相对整张画面的中心，范围 0 到 1。也可以写 `x,y,w,h` 矩形，点矩形中心。滑块和结算仍点画面中部，不走这份文件。
