# 项目侧测试用例（项目管理员）

适用范围：项目管理员（PROJECT_ADMIN）；**电脑端**。  
约定：`P` = Pass，`F` = Fail，`B` = Blocked。

---

## A. 登录与端限制

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| P-A01 | 电脑浏览器手机号登录项目管理员 | 默认进入「项目」列表；侧栏仅项目/排班/实施人员/系统配置 | |
| P-A02 | 手机浏览器登录同一账号 | 提示请使用电脑端（pc-only），无销售手机工作台 | |
| P-A03 | 侧栏确认无客户/商机/审批/日报菜单 | 不可见销售侧菜单 | |
| P-A04 | 管理员切换到项目管理员再退出切换 | 可进入项目视角并回到管理员 | |

---

## B. 项目来源（与销售联动）

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| P-B01 | 项目列表为空时查看文案 | 提示合同签署通过后自动创建 | |
| P-B02 | 销售提审合同 + 销管审批通过 | 项目列表新增对应项目 | |
| P-B03 | 销管免审签署合同 | 同样自动出现项目 | |
| P-B04 | 合同仍待审核时刷新项目列表 | **不应**出现已生效项目 | |
| P-B05 | 打开新项目概览 | 客户/合同/状态信息与合同侧一致 | |

---

## C. 项目计划

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| P-C01 | 进入项目 → 项目计划 Tab | 可选择启用中的项目模型或维护阶段 | |
| P-C02 | 创建/调整阶段任务并保存 | 刷新后仍在 | |
| P-C03 | 为任务指定执行人 | 人选来自可排班人员；保存成功 | |
| P-C04 | 使用已停用的项目模型 | 不可用于新计划（或列表中不可选） | |
| P-C05 | 修改概览计划起止/备注 | 保存成功并回显 | |

---

## D. 资源排班

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| P-D01 | 打开侧栏「资源排班」 | 显示人员列表与时间控件（按月/周） | |
| P-D02 | 切换按月 ↔ 按周 | 视图区间变化，无报错 | |
| P-D03 | 按人员类型筛选 | 列表过滤正确 | |
| P-D04 | 在有项目时进入资源明细并分配人天 | 分配成功；人员本月人天/项目数更新 | |
| P-D05 | 无项目时查看总览 | 显示「暂无可见项目」，不崩溃 | |
| P-D06 | 从排班返回项目列表 | 回到 `/projects` | |

---

## E. 实施人员与成本

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| P-E01 | 打开「实施人员 → 人员信息」 | 显示人员及当月成本概况 | |
| P-E02 | 修改某人类型（如实施→顾问）并保存 | 刷新后类型保持 | |
| P-E03 | 打开「人员成本」维护月成本/调整 | 有效月成本更新；排班侧费率展示合理 | |
| P-E04 | 停用人员（若产品支持）后排班 | 不可再排入或按规则提示 | |

---

## F. 系统配置（项目）

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| P-F01 | 打开系统配置 | 可见项目相关项；不可见纯销售/全局敏感项（按权限） | |
| P-F02 | 新建并启用项目模型 | 项目计划中可选该模型 | |
| P-F03 | 停用模型后再开新计划 | 不可再选该模型 | |

---

## G. 账号切换

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| P-G01 | 项目管理员切换到项目经理 | 菜单/数据范围符合项目经理 | |
| P-G02 | 切换到项目人员 | 符合项目人员可见范围 | |
| P-G03 | 尝试切换到销售 | 不可选或不允许 | |
| P-G04 | 退出切换 | 回到项目管理员 | |

---

## H. 回归冒烟（每次发版建议必跑）

1. P-A01、P-A02  
2. P-B02（或用已有测试合同复验）  
3. P-C01、P-D01、P-E01  
4. P-G01、P-G04  

---

## 跨系统联调用例（销售 + 项目）

| ID | 步骤 | 预期 | 结果 |
|----|------|------|------|
| X-01 | 销售新建客户→商机→合同提审 | 销管审批列表出现合同 | |
| X-02 | 销管通过合同 | 项目管理员项目列表出现新项 | |
| X-03 | 项目管理员完成计划+排班 1 人天 | 人员本月投入 > 0；项目费用有反映 | |
