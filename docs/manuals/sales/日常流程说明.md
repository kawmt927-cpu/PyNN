# 销售日常流程使用说明

面向角色：**销售**  
系统地址：https://crm.pynntech.com  
更细的功能说明见 [销售操作手册](./操作手册.md)。

---

## 一、怎么进系统

**推荐：企业微信里打开应用**（自动登录，手机端）。

| 场景 | 进入哪里 |
|------|----------|
| 手机企微 / 手机浏览器 | 手机端「今日」 |
| 电脑浏览器 | 电脑端「今日工作」 |

首次用企微：若提示未绑定，按页面提交开通申请，等管理员开通后再进。  
也可用 **手机号 + 密码** 在登录页登录（需已激活账号）。

---

## 二、手机底栏（外勤主用）

| 底栏 | 做什么 |
|------|--------|
| **今日** | 看今天打卡、日报状态、待办入口 |
| **打卡** | 拜访定位、记往来 |
| **日报** | 晚上跟 AI 整理并提交今日日报 |
| **指标** | 看本人指标汇总 |
| **更多** | 客户 / 商机 / 合同 / 待跟进；可切到电脑端 |

电脑端左侧菜单对应：今日工作、日报管理、计划与任务、客户、商机、待跟进、合同。

---

## 三、推荐的一天怎么用

### 早上：先看「今日」

1. 打开企微应用 → **今日**。  
2. 看 **待办**：有没有本周任务、已到期跟进。  
3. 看 **今日日报** 状态：未开始 / 对话中 / 待确认 / 已提交。

电脑端可打开 **今日工作**、**待跟进**，处理即将到期的下次往来。

### 拜访中：一定先「打卡」

1. 底栏点 **打卡**（或今日里的「往来打卡」）。  
2. 允许定位后，按实际情况选一种：

| 方式 | 适合什么时候 |
|------|----------------|
| **当场录入往来** | 能马上写清拜访内容、下次计划 |
| **仅打卡，晚上再补** | 赶场没空写，晚上在日报里补 |
| **无客户打卡** | 临时路过、暂不关联客户 |

3. 系统里还没有这家医院/客户时：打卡页可 **快捷新建客户**（也可新建商机）。  
4. 当天有「待补往来」的打卡，下班前尽量补全，再写日报。

> 定位依赖公司配置的高德 Key；未配置时仍可打卡，地址可能解析不全。

### 白天：维护客户与商机

| 要做的事 | 手机 | 电脑 |
|----------|------|------|
| 查 / 新建客户 | 更多 → 客户 | 侧栏「客户」→ 新增客户 |
| 查 / 新建商机 | 更多 → 商机 | 侧栏「商机」 |
| 写跟进 | 客户/商机详情里 | 客户或商机的跟进页 |
| 看合同 | 更多 → 合同（以查阅为主） | 侧栏「合同」 |
| 认领公海客户 | 公海池申请认领 | 同左，等销管审批 |

说明：

- **跟进可以随时记**，不必等写日报。  
- **签约 / 创建合同** 请找销售管理在电脑端操作；销售可查看本人合同、登记回款、上传附件。  
- 复杂编辑（大段资料、合同附件等）建议用 **电脑浏览器**。

### 傍晚：写并提交「日报」

1. 手机底栏 **日报**（或电脑「今日工作 → 今日日报」）。  
2. 用文字（或语音，若已开通）跟助理说清楚：今天见了谁、谈了什么、下一步。  
3. 看助理整理的内容 → **确认提交**。  
4. 提交后，当日仅打卡未写完的往来，可在对话里一并补全。

历史日报：电脑端 **日报管理**（只能看自己的）。

---

## 四、最少要做到的事（开用标准）

每天建议至少完成：

1. **有拜访就打卡**（有定位）。  
2. **当天提交日报**（即使外出少，也可简短说明）。  
3. **到期跟进不拖**：在「待办 / 待跟进」里处理已到期项。

客户、商机资料有变化时及时改，避免只记在微信里。

---

## 五、销售不能自己做的事

- 审批（公海认领、合同审核）——找销管  
- 新建 / 编辑合同正文、从商机「创建合同」——找销管  
- 直接把公海客户分给自己（只能 **申请认领**）  
- 给别人指派周任务、改团队销售目标  
- 系统配置、用户管理  

---

## 六、常见问题

| 情况 | 怎么办 |
|------|--------|
| 企微打开是空白 / 滚不动 | 在应用内上下滑内容区；仍异常可换手机浏览器打开同一地址 |
| 上传合同附件提示过大 | 单文件不超过 **20MB**；压缩后再传 |
| 日报里 AI 没反应 | 联系管理员检查 AI 配置 |
| 打卡没有详细地址 | 仍可提交；联系管理员配置定位 Key |
| 手机想用电脑版菜单 | 更多 → **切换到电脑端** |
| 账号进不去 | 确认企微已开通绑定，或用已激活的手机号密码登录 |

---

## 七、一句话记住

**企微进「今日」→ 拜访用「打卡」→ 晚上「日报」提交；客户/商机在「更多」维护；要签约找销管在电脑端建合同。**
