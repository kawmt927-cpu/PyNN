# 销售侧测试用例

适用范围：销售、销售管理；PC + 手机。  
约定：`P` = Pass，`F` = Fail，`B` = Blocked。执行时填写实际账号与环境。

---

## A. 登录与端落地

| ID | 角色 | 端 | 步骤 | 预期 | 结果 |
|----|------|----|------|------|------|
| S-A01 | 销售 | 手机 | 手机浏览器打开登录页，账号密码登录 | 进入 `/mobile` 销售底栏（今日/打卡/日报/待办/更多） | |
| S-A02 | 销管 | 手机 | 同上 | 进入 `/mobile` 销管底栏（今日/往来/日报/审批/更多） | |
| S-A03 | 销售 | PC | 电脑浏览器登录 | 进入电脑端「今日工作」，侧栏无「审批」 | |
| S-A04 | 销管 | PC | 电脑浏览器登录 | 进入「今日工作」团队视图，侧栏有「审批」 | |
| S-A05 | 销售 | 手机 | 登录前先打开过 PC 路径书签再登录 | 仍落地手机端，不进 PC 壳 | |
| S-A06 | 任意销售侧 | 手机 | 「更多 → 切换到电脑端」 | 可浏览 PC 布局；侧栏有「切换到手机端」可切回 | |
| S-A07 | 项目角色 | 手机 | 项目账号打开 `/mobile` | 提示请用电脑端（pc-only） | |

## B. 往来打卡

| ID | 角色 | 端 | 步骤 | 预期 | 结果 |
|----|------|----|------|------|------|
| S-B01 | 销售 | 手机 | 打卡页选「往来打卡」，新增客户并提交 | 客户创建成功；打卡出现在今日列表 | |
| S-B02 | 销售 | 手机 | 关联已有客户，填往来+下次计划，获取定位后提交 | 成功；待跟进中出现下次计划 | |
| S-B03 | 销售 | 手机 | 选「无客户打卡」仅定位提交 | 成功且无需完善往来 | |
| S-B04 | 销售 | 手机 | 客户等级非「无意向」时不填下次计划 | 校验拦截，无法提交 | |
| S-B05 | 销售 | 手机 | 打卡后点「新建商机」 | 可为该客户创建商机并关联 | |
| S-B06 | 销管 | 手机 | 底栏「往来」完成一次本人打卡 | 与销售相同可提交；无需写日报 | |
| S-B07 | 销售 | PC | 今日工作 → 往来打卡卡片 | 进入打卡能力，记录回显在今日工作记录 | |

## C. 日报

| ID | 角色 | 端 | 步骤 | 预期 | 结果 |
|----|------|----|------|------|------|
| S-C01 | 销售 | 手机 | 底栏日报，对话整理并提交 | 状态变为已提交 | |
| S-C02 | 销售 | PC | 日报管理查看当日与历史日 | 可见本人打卡/往来/日报摘要 | |
| S-C03 | 销管 | PC/手机 | 日报管理切换不同销售与日期 | 可查阅团队数据；无「代替销售提交」入口 | |
| S-C04 | 销管 | 手机 | 查看底栏 | 无销售「写日报」式入口；有团队日报查阅 | |

## D. 客户

| ID | 角色 | 端 | 步骤 | 预期 | 结果 |
|----|------|----|------|------|------|
| S-D01 | 销售 | PC | 新增客户 | 负责人=本人；出现在我的客户 | |
| S-D02 | 销管 | PC | 新增客户并指定负责人或公海 | 按选择落库 | |
| S-D03 | 销售 | PC | 公海客户申请认领 | 产生待审批认领单 | |
| S-D04 | 销售 | PC | 对同一客户重复申请认领 | 被拒绝或提示已有 pending | |
| S-D05 | 销管 | PC/手机 | 审批通过认领 | 负责人=申请人；列表从公海消失 | |
| S-D06 | 销管 | PC | 审批拒绝认领 | 客户仍在公海 | |
| S-D07 | 销管 | PC | 直接分配公海给销售 | 负责人变更；相关 pending 作废 | |
| S-D08 | 销售 | 手机 | 更多→客户→新增，再写跟进 | 可新建；本人客户可跟进 | |
| S-D09 | 销售 | PC | 打开他人客户 | 不可见或不可写跟进（除非协助负责人/例外规则） | |

## E. 商机

|----|------|----|------|------|------|
| S-E01 | 销售 | PC | 新建商机（选客户） | 出现在未签约列表/漏斗 | |
| S-E02 | 销售 | 手机 | 更多→商机→新增 | 可选客户并创建成功 | |
| S-E03 | 销售 | PC | 推进阶段、关联往来 | 详情与漏斗更新 | |
| S-E04 | 销售 | 手机 | 打开已签约/放弃入口 | 以查阅为主；签约操作引导电脑端 | |

## F. 合同与审批

| ID | 角色 | 端 | 步骤 | 预期 | 结果 |
|----|------|----|------|------|------|
| S-F01 | 销售 | PC | 从商机发起合同并提交 | 状态待审核；销管审批出现该单 | |
| S-F02 | 销管 | PC/手机 | 合同审核驳回 | 销售可见驳回原因并可再提 | |
| S-F03 | 销管 | PC/手机 | 合同审核通过 | 合同生效；**自动生成项目**（项目账号可见） | |
| S-F04 | 销管 | PC | 销管直接新建合同 | 免审生效并自动建项目 | |
| S-F05 | 销售 | PC | 尝试编辑已通过合同正文 | 不可编辑（或仅允许管理类角色） | |
| S-F06 | 销管 | 手机 | 审批页切换「客户认领/合同」「待审批/已处理」 | 筛选正确，计数正确 | |
